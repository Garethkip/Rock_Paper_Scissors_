# 🪨 Rock Paper Scissors

[🔗 **Play the Game Live**]([http://www.myrockpaperscissors.com/](https://garethkip.github.io/Rock_Paper_Scissors_/))

A simple **Rock Paper Scissors** game built with HTML, CSS, and JavaScript. Choose rock, paper, or scissors and play against the computer.

## 🎮 How to Play

1. Choose one of the three options:
   - 🪨 Rock
   - 📄 Paper
   - ✂️ Scissors
2. The computer randomly selects its choice.
3. The winner is determined using the standard rules:
   - 🪨 Rock beats ✂️ Scissors
   - 📄 Paper beats 🪨 Rock
   - ✂️ Scissors beats 📄 Paper
4. If both choices are the same, the round is a draw.

## ✨ Features

- Player vs. computer gameplay
- Random computer choices
- Automatic winner detection
- Score tracking
- Simple and responsive interface
- Interactive buttons

## 🛠️ Technologies Used

- **HTML5** – Structure
- **CSS3** – Styling and layout
- **JavaScript** – Game logic and interactivity
